# נחלת הארי — אפיון בנייה

אתר קטלוג יוקרתי לתשמישי קדושה. **ללא עגלה/תשלום** — כל הזמנה יוצאת בוואטסאפ אישי.

## מותג ושפה ויזואלית
- שם: **נחלת הארי** · לוגו: אריה זהב עם כתר על נייבי · מוטיב: להבה ("שלי").
- כיוון: **יוקרה שקטה / טבעית** — שמנת, פשתן, טאופ, זהב מאופק, נייבי לעוגן.
- טיפוגרפיה: `Frank Ruhl Libre` (כותרות, סריף) + `Heebo` (גוף). RTL.
- פלטה: cream #F7F1E6 · linen #E8DDCB · travertine #CFC3AD · taupe #A99983 · ink #1F1B16 · navy #071426 · gold #B88A35 · gold-soft #C8A45E · olive #69765A · wheat #D8BF7A.

## מנגנון הזמנה
- אין cart/checkout/Stripe. כל מוצר → כפתור **"לתיאום הזמנה אישית"** שפותח
  `wa.me/972544500168?text=...` עם הודעה שכוללת שם מוצר, קטגוריה ומק"ט.

## מודל תוכן
- **קטגוריות** (`data/categories.json`): `id, name, description, image?`. תמונת נושא + טקסט לכל קטגוריה.
- **מוצרים** (`data/products.json`): `id, name, description, category, images[], material?, blessing?, personalName?, isCustomerOrder?, createdAt`. אין מחיר.
- מוצרים עם `personalName` מסומנים `isCustomerOrder=true` → מוצגים גם בדף **"הזמנות של לקוחות"** (גלריית עבודות).

## דפים
- `/` בית · `/shop` + `/shop/[id]` (קטגוריה/מוצר) · `/category/[id]` · `/customers` (הזמנות לקוחות) · `/about`.
- `/admin`: כניסה (shon / AriAzulay) → ניהול קטגוריות (הוספה/הסרה), מוצרים (הוספה/הסרה + העלאת תמונות), ועריכת טקסטים בדפים (`data/content.json`).

## שלבי בנייה
1. פלטה + פונטים (globals, layout). 2. מיון 66 התמונות → שיבוץ. 3. עמוד בית + נאב + פוטר + כפתור וואטסאפ.
4. עמודי קטגוריה + מוצר. 5. דף הזמנות לקוחות. 6. הסרת cart/checkout/Stripe. 7. admin: קטגוריות + טקסטים. 8. ביקורת קודקס + הרצה.
